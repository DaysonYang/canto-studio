預設搜尋 `394052`，使用 **394052 嚴格**，也可切換 **0243 寬鬆**（六調依次為 `334042`）。高級選項中，「番茄醬牛肉麵不吃辣」在寬鬆／嚴格模式分別是 `334022342`／`394022342`，「詩史試時市是」是 `334042`／`394052`。表格保留原粵拼及六調，切換只更新編碼。入聲 7／8／9 分別沿用第 1／3／6 調。

智能搜尋升級的使用、資料、排序公式、驗證與部署詳見 [智能搜尋說明](SMART-SEARCH.md)。

無套件、無 API 金鑰、無需付費服務。詞庫已打包，搜尋完全離線。

頂部可切換「詞組搜尋」及「自由拼詞」。詞組結果可多選詞性；自由拼詞可按切法分組、各自篩選和選詞，保存、收藏及恢復組合。推薦只從槽位候選中選，不改鎖定詞。獨立整句搜尋與在線 AI 入口均已移除。詳見 [自由拼詞與對照實測](COMPOSE.md)。

每個結果詞塊的 ▶ 按鈕可播放／停止裝置提供的本地粵語合成朗讀。僅選用 localService 的 yue 或 zh-HK 語音，不回退普通話、不使用遠端語音服務；缺少時提示在系統安裝粵語語音。翻頁或重新搜尋會停止播放。本功能按原詞形朗讀，語音引擎自行判讀多音字，不保證等同所列粵拼，並非逐詞標準讀音錄音；需以所列粵拼核對。

詞組搜尋只找符合整段編碼的完整詞條。無結果時會提示，需分段選詞可自行切換到「自由拼詞」。

支援數字與歌詞混合輸入，例如 `0033天窗叫`、`紅糖93甜`：每個數字代表一個待填字的聲調，文字位置辨音並保留原字（簡繁兼容）；純文字輸入仍用於查找同聲調替代詞。押韻範圍的末尾 1–3 個位置必須全為文字，若包含數字則提示，不能從數字猜韻母。

「自由拼詞」有自動拆分及分詞輸入框，例如 `0033 + 334` 改為 `00 + 33 + 334`，按 Enter 或「套用分詞」更新槽位。合併後須等於目前聲調編碼，並保留範圍未變的選詞。

搜尋框旁的「押韻」開關可限制末尾 1–3 字的粵拼韻母逐字相同（去聲母與聲調，保留韻尾，m/ng 成音節獨立處理），同時維持原本聲調條件；完整字詞與跨分詞邊界的組合皆適用。依目前選定的輸入讀音比對；純數字無法提供韻母，需改輸入字詞。字數不足會提示，不自動縮減。此為嚴格韻母相同，不含寬韻或近韻。

搜尋框同時接受數字與簡繁字詞。輸入字詞後依詞庫匹配，優先較少分段、同等情況長詞優先；顯示各段粵拼及自訂聲調編碼，多音讀法可從下拉選單選擇，預設讀法不是語境判斷。右側可直接選擇「完整字詞」或「字詞組合（可拆分）」。未知字不猜讀音。切換讀音會自動更新結果；聲調數字仍可直接輸入。

## 啟動

直接用瀏覽器開啟 index.html 即可使用。亦可在此資料夾執行：

```sh
python3 start.py
```

再開啟 http://127.0.0.1:8765 。更換埠：`python3 start.py 8888`。按 Ctrl+C 結束。

## 使用

1. 輸入聲調數字或字詞，按「查找字詞」。切換模式會保留手輸的數字、歌詞、鎖定及排序設定，並重新搜尋。若數字不適用於新模式（例如 `9` 或 `5` 不適用於 0243），會提示，不自動轉換；字詞會按原粵拼重新編碼。內建示例會跟隨模式更新。
2. 詞組搜尋不拆分，結果預設每頁 12 項，可自訂每頁條數。自由拼詞可自訂分詞，各槽每頁 10 項。
3. 草稿中點字卡鎖定位置，再搜尋。`□` 代表空白；鎖定兼容簡繁字形。更改編碼清除鎖定，更改歌詞只保留原位原字的鎖定。
4. 每個候選顯示逐字目標數字、實際詞庫粵拼與來源。按「填入」替換草稿並保留鎖定；按「複製」複製草稿與目標編碼。

5. 右上角選擇「简体」或「繁體」，切換整個界面、候選詞與草稿字形，保留鎖定位置、編碼及結果頁，瀏覽器會記住偏好。複製時使用當前草稿字形。轉換使用隨附 OpenCC 字表，完全離線。

「红糖水真系甜」的繁體是「紅糖水真係甜」：`hung4 tong4 seoi2 zan1 hai6 tim4`，聲調 `442164`，嚴格編碼 `009320`，寬鬆編碼 `003320`。簡體 `系` 可匹配原詞庫的 `係`；同一簡體對應多個繁體時可能出現多個原詞條，仍按各自詞庫讀音搜尋。簡體轉繁體並非一一對應，需自行核對歧義。詞條可拆成「紅糖 + 水 + 真係 + 甜」。

## 原始碼與演算法

- engine.js：讀音轉碼、編碼索引、鎖定過濾、連續分詞 DAG、BigInt 動態規劃計數及按排名取分詞、混合進位取候選。最多 24 字，搜尋覆蓋所有切點；只有每段都有詞庫命中的完整路徑才列出。
- app.js / index.html / style.css：介面；data/dictionary.js：實際開放詞庫；data/provenance.json：版本、筆數、原檔校驗。
- scripts/build_dictionary.py：重建詞庫。先取得上游倉庫，再執行 `python3 scripts/build_dictionary.py /path/to/rime-cantonese`。重建會覆蓋資料及授權副本，更新來源紀錄。
- variants.js / data/variants.js：基於 OpenCC 字表的最長詞組匹配及單字轉換，不是完整 OpenCC 引擎。只使用等長轉換以保持逐字編碼位置；鎖定按單字簡體歸一比對。重建：`python3 scripts/build_variants.py /path/to/OpenCC`。
- tests/engine.test.cjs、tests/encoding.test.cjs：使用 Node.js 18+ 執行 `node tests/engine.test.cjs` 及 `node tests/encoding.test.cjs`，驗證精確檢索及兩種編碼的讀音、排序與分詞。

詞庫搜尋不使用 AI 造詞。具語料記錄時會顯示 HKCanCor 詞次、詞性與共現詞；不提供未經來源驗證的詞義。多音字按各讀音列出，需按語境選取。來源與授權詳見 SOURCES.md。
